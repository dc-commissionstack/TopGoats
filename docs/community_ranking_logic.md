# Community Ranking System & Gamification Logic: Top Goats

## 1. Ranking System Overview: The "Herd" Hierarchy

The "Top Goats" ranking system is designed to reward both social engagement and commercial success within the ecosystem. Users progress through tiers based on cumulative Experience Points (XP).

| Rank Level | Title | XP Required | Badge Icon |
| :--- | :--- | :--- | :--- |
| **Level 1** | **Kid** | 0 | 🍼 |
| **Level 2** | **Yearling** | 500 | 🌿 |
| **Level 3** | **Ram** | 2,500 | 🐏 |
| **Level 4** | **Great Goat** | 10,000 | 🏔️ |
| **Level 5** | **Top Goat** | 50,000 | 👑 |

---

## 2. XP Mechanics: How to Earn Rank

XP is earned through a mix of community contribution, platform utility, and sales performance.

### A. Community Engagement (Social)
*   **Post Created:** +10 XP
*   **Comment/Reply:** +5 XP
*   **Upvote Received:** +2 XP
*   **Accepted Answer (Technical Forums):** +50 XP
*   **Weekly Check-in Streak:** +20 XP (multiplier for consecutive weeks)

### B. Platform Utility (Sovereignty)
*   **First Track Uploaded:** +100 XP
*   **Copyright Fingerprint Secured:** +50 XP (per track)
*   **Profile Completion (Bio, Links, Banner):** +200 XP
*   **Linking External Storefronts:** +50 XP

### C. Commercial Success (Commerce)
*   **First Sale Made:** +500 XP
*   **Every $10 in Sales (GMV):** +50 XP
*   **5-Star Review Received:** +25 XP

---

## 3. Badges & Special Achievements

Badges are non-linear rewards for specific behaviors that don't always align with XP tiers.

*   **"Founding Goat":** Exclusive to the first 100 beta users.
*   **"IP Shield":** Awarded for securing 10+ tracks with copyright fingerprinting.
*   **"The Collaborator":** Awarded for tracks with multiple royalty splits (3+ artists).
*   **"Merchant Goat":** Awarded after reaching $1,000 in lifetime GMV.

---

## 4. Rank Perks & Incentives

To encourage high-quality participation and retention, each rank unlocks specific platform benefits.

| Rank | Perks |
| :--- | :--- |
| **Kid** | Basic profile, forum access, 5.0% transaction fee. |
| **Yearling** | Custom profile colors, ability to create "Polls" in forums. |
| **Ram** | Early access to new features (Beta lab), 4.5% transaction fee. |
| **Great Goat** | Featured placement on the "Discovery" feed (1x per month), custom URL slug. |
| **Top Goat** | **VIP Sovereignty Support** (direct line to legal/IP advisors), 4.0% transaction fee, "Verified" gold checkmark. |

---

## 5. Community Voting & "Goat of the Month"
*   **Peer Recognition:** Each month, the community votes on one "Top Goat" from the top tier.
*   **Reward:** The winner receives a site-wide banner takeover for 24 hours and a 0% transaction fee for the following month.
